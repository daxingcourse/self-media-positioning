# 🧋 奶茶定位所｜自媒體定位小測驗

奶茶色系、可愛活潑的自媒體定位系統。回答幾個問題，就能看出你的創作者特質、奶茶人格，以及最適合你的自媒體方向。

## 功能

1. **選茶底**：暱稱、興趣領域（16 選 1–5）、獨特經歷
2. **12 題特質測驗**：知識力、表達力、美感力、共感力、行動力
3. **加配料**：受眾、目標、露臉意願、每週時間
4. **定位報告**
   - 奶茶人格（伯爵奶茶・知識導師、黑糖珍奶・人氣主持、芋泥波波・美感創作者、蜂蜜鮮奶・療癒陪伴者、焙茶拿鐵・實驗紀錄家）
   - 五大特質雷達圖、天賦與盲點
   - 前 3 名適合賽道（契合度、形式、變現、內容支柱）
   - 一句話定位、社群簡介、平台與頻率、一週內容菜單、選題靈感
   - 複製報告／下載 .md／列印存 PDF

5. **寄送報告＋收名單（選用）**：填 Email 立即收到完整報告，之後自動寄出一系列信件，並推薦你的課程／產品

網站本身只有一個 `index.html`，不用登入，支援手機與深色模式。寄信、名單和課程推薦用 Google 試算表當後台，設定方式請看 👉 [backend/後台設定教學.md](backend/後台設定教學.md)

## 上線（GitHub Pages，免費）

1. 到這個專案的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
3. 等 1–2 分鐘，網址會是：`https://<你的帳號>.github.io/self-media-positioning/`

## 自己改內容

都在 `index.html` 裡：

- 顏色：最上面 `:root` 的色票（`--milk`、`--tea`、`--caramel`…）
- 題目：搜尋 `const QUIZ`
- 奶茶人格文案：搜尋 `const PERSONAS`
- 賽道與內容支柱：搜尋 `const NICHES`
- 後台網址：搜尋 `const ENDPOINT`

信件內容、課程產品、寄送天數都在 Google 試算表裡改，不用動程式。
