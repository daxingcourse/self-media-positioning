# 🧋 奶茶定位所｜後台設定教學

## 整個系統怎麼運作

```
測驗者做完測驗
   ↓ 結果頁「📩 把完整報告寄到信箱」填 Email、勾選同意  ← 這一步就是「收集名單」
   ↓
Google Apps Script（你的後台程式）
   ├─ 把資料存進 Google 試算表「名單」分頁
   ├─ 立刻透過 Resend 寄出完整報告信
   └─ 每小時檢查一次，依「序列信」設定的天數寄後續信件（含課程推薦）
   ↓
你在「網頁後台」admin.html 看數據、管理名單、改信件、加課程
```

- **資料存在哪**：你自己的 Google 試算表（名單、序列信、產品、設定）
- **信從哪寄**：Resend，用你自己網域的信箱（例如 `hello@你的網域.com`）
- **在哪管理**：`https://daxingcourse.github.io/self-media-positioning/admin.html`（用密碼登入），也可以直接改試算表

---

## 第 1 步：建立試算表、貼上程式（約 3 分鐘）

1. 打開 https://sheets.new ，建立新試算表，命名「奶茶定位所後台」
2. 上方選單：**擴充功能 → Apps Script**
3. 把編輯器裡原本的程式碼全部刪掉
4. 打開這個專案的 [`backend/Code.gs`](./Code.gs)，**全部複製**貼上，按 💾 儲存

## 第 2 步：初始化

1. 在 Apps Script 上方的函式選單選 **`setup`**，按 **▶ 執行**
2. 跳出授權視窗：選你的帳號 → 若出現「Google 尚未驗證這個應用程式」，點 **進階 → 前往（不安全）**（這是你自己的程式）→ **允許**
3. 回到試算表，會多出：**儀表板、名單、信件序列、產品、設定** 分頁，以及上方的「🧋 奶茶定位所」選單

## 第 3 步：設定 Resend（約 10 分鐘，需要你自己的網域）

1. 到 https://resend.com 註冊
2. 左側 **Domains → Add Domain**，輸入你的網域（建議用子網域，例如 `mail.你的網域.com`）
3. Resend 會列出幾筆 DNS 紀錄（TXT／MX）。到你買網域的地方（GoDaddy、Cloudflare、Gandi…）的 DNS 設定，**照抄新增**
4. 回 Resend 按 **Verify**，等狀態變成 ✅ Verified（通常幾分鐘，最久可能幾小時）
5. 左側 **API Keys → Create API Key**，權限選 **Sending access**，複製 `re_` 開頭的金鑰
6. 回到試算表：選單 **🧋 奶茶定位所 → ② 設定 Resend API 金鑰**，貼上
7. 到「設定」分頁，**寄件信箱** 填 `hello@mail.你的網域.com`（網域要跟第 2 步驗證的一樣）

> 💡 Resend 免費方案：每天 100 封、每月 3,000 封。超過的信會自動留到下一個小時／隔天再寄。

## 第 4 步：設定網頁後台密碼

選單 **🧋 奶茶定位所 → ③ 設定網頁後台密碼**，輸入至少 8 個字的密碼。

## 第 5 步：部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**
2. 齒輪選 **網頁應用程式**
3. 執行身分：**我**；誰可以存取：**所有人**
4. 按 **部署**，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）

## 第 6 步：接到網站

把網址傳給 Claude 幫你填，或自己改專案裡的 **`config.js`**：

```js
window.MILKTEA_CONFIG = {
  ENDPOINT: 'https://script.google.com/macros/s/你的網址/exec',
};
```

推上 GitHub 約 1–2 分鐘後：

- 網站結果頁會出現「📩 把完整報告寄到信箱」與「🎁 推薦給你」
- 網頁後台 `admin.html` 可以登入了

## 第 7 步：寄測試信

登入 `admin.html` → **⚙️ 寄信設定 → 寄全部測試信**，確認報告信和每封序列信的樣子。

## 網頁後台功能（admin.html）

| 分頁 | 可以做什麼 |
|---|---|
| 📊 儀表板 | 總名單、近 7 天新增、序列寄送中、退訂數、近 14 天趨勢、奶茶人格分布、熱門賽道、寄信是否設定完成 |
| 👥 名單 | 搜尋、依狀態／人格篩選、改狀態（停寄或重新寄）、匯出 CSV |
| ✉️ 序列信 | 新增／刪除／排序信件、設定第幾天寄、啟用開關、點選插入變數、單封寄測試 |
| 🎁 課程產品 | **之後加入課程的地方**：名稱、介紹、價格、連結、按鈕文字、適合人格、優先序、是否顯示在結果頁 |
| ⚙️ 寄信設定 | Resend 金鑰、寄件信箱、寄件人名稱、回覆信箱、寄送時段、每小時上限、寄測試信、手動處理佇列 |
| 🌐 網站設定 | LINE 官方帳號按鈕（結果頁＋每封信）、Google AdSense 廣告代碼、廣告開關與位置 |

### 信件可用的變數

`{暱稱}` `{人格}` `{副口味}` `{賽道1}` `{賽道2}` `{受眾}` `{定位句}` `{產品名稱}` `{產品介紹}` `{產品價格}` `{產品連結}` `{網站網址}` `{寄件人}`

**`{課程卡片}`**：會變成一張課程卡片（含按鈕），內容是推薦給這個人的產品。

### 課程怎麼被推薦

1. 只看「啟用」的產品
2. 「適合人格」包含這個人的人格（或設為全部）
3. 「優先序」數字最小的優先
4. 網站結果頁最多顯示 2 個（還要勾「結果頁顯示」）；信件的 `{課程卡片}` 顯示 1 個

> 範例資料裡的兩個產品是假的（example.com），**記得改成你自己的課程**或關掉。

## 常見問題

**改了 Code.gs 之後要做什麼？**
部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署。網址不會變。

**沒有網域可以先用嗎？**
可以。「設定」分頁的 **寄信方式** 改成 `gmail`，就會用你的 Gmail 寄（每天約 100 封）。之後有網域再改回 `resend`。

**信被分到垃圾郵件？**
確認 Resend 網域是 ✅ Verified、寄件信箱用同一個網域；報告信請大家「加入聯絡人」；序列信避免一直出現「免費」「限時」等字眼。

**後台密碼忘了？**
試算表選單 ③ 重新設定一次就好。

**個資提醒**
名單只存在你自己的 Google 試算表。表單有「同意接收內容、可隨時取消訂閱」勾選欄，每封信都有退訂連結（也有 List-Unsubscribe 標頭，Gmail 會顯示「取消訂閱」按鈕）。
