# 🧋 奶茶定位所｜後台設定教學

後台就是一份 **Google 試算表**，免費，不用架伺服器。設定好之後：

- 測驗者在結果頁填 Email → 名單自動存進試算表，**立刻收到完整報告信**
- 之後依照你設定的天數，**自動寄出一系列信件**（預設第 1、3、5、7、10 天）
- 你在試算表的「產品」分頁加入課程或產品，**結果頁和信件都會自動推薦**給適合的奶茶人格
- 每封信都有「取消訂閱」連結，退訂後就不會再寄

---

## 第 1 步：建立試算表、貼上程式（約 3 分鐘）

1. 打開 https://sheets.new ，建立一份新的試算表，命名為「奶茶定位所後台」
2. 上方選單：**擴充功能 → Apps Script**
3. 把編輯器裡原本的程式碼全部刪掉
4. 打開這個專案的 [`backend/Code.gs`](./Code.gs)，**全部複製**貼上
5. 按上方 💾 儲存

## 第 2 步：初始化後台

1. 在 Apps Script 編輯器上方的函式選單選 **`setup`**，按 **▶ 執行**
2. 第一次會跳出授權視窗：
   - 選你的 Google 帳號
   - 如果出現「Google 尚未驗證這個應用程式」，點 **進階 → 前往（不安全）**（這是你自己的程式，所以沒問題）
   - 按 **允許**（需要「管理試算表」和「以你的名義寄信」的權限）
3. 回到試算表，會看到多了這幾個分頁：**儀表板、名單、信件序列、產品、設定**

> 之後試算表上方會多一個「🧋 奶茶定位所」選單，可以寄測試信、手動處理佇列。

## 第 3 步：部署成網頁應用程式

1. 回到 Apps Script，右上角 **部署 → 新增部署作業**
2. 左邊齒輪選 **網頁應用程式**
3. 設定：
   - 說明：`奶茶定位所 v1`
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按 **部署**，複製「網頁應用程式網址」（長得像 `https://script.google.com/macros/s/AKfy.../exec`）

## 第 4 步：把網址接到網站

把剛剛的網址傳給 Claude，請它幫你填進去；或自己改：

打開 `index.html`，搜尋 `const ENDPOINT = '';`，改成：

```js
const ENDPOINT = 'https://script.google.com/macros/s/你的網址/exec';
```

存檔推上 GitHub，約 1–2 分鐘網站就會出現「📩 把完整報告寄到信箱」區塊。

## 第 5 步：寄測試信給自己

試算表上方選單 **🧋 奶茶定位所 → 寄測試信給自己**，你的信箱會收到報告信＋全部序列信的預覽，確認內容和樣式。

## 日常管理

### 📋 名單分頁
每個留 Email 的人一列：暱稱、奶茶人格、推薦賽道、五大特質分數、目前寄到第幾封、狀態（訂閱中／已退訂／序列完成）。

- 想停止寄給某人：把「狀態」改成 `已退訂`
- 想讓某人重收：「已寄序列」改回 `0`、「狀態」改 `訂閱中`、「下次寄送」填現在時間

### ✉️ 信件序列分頁

| 欄位 | 說明 |
|---|---|
| 順序 | 寄送順序（1、2、3…） |
| 第幾天寄 | 從留 Email 那天算起第幾天 |
| 主旨／內文 | 純文字即可，空一行＝新段落 |
| 啟用 | 打勾才會寄 |

**可以用的變數**（會自動換成每個人的資料）：

`{暱稱}` `{人格}` `{副口味}` `{賽道1}` `{賽道2}` `{受眾}` `{定位句}` `{產品名稱}` `{產品介紹}` `{產品價格}` `{產品連結}` `{網站網址}` `{寄件人}`

**`{課程卡片}`**：放在內文裡，會變成一個漂亮的課程卡片（含按鈕），內容來自「產品」分頁推薦給這個人的產品。

想加第 6、7 封信？直接往下新增一列就好。

### 🎁 產品分頁（之後加入課程的地方）

| 欄位 | 說明 |
|---|---|
| 產品ID | 自己取的代號，不要重複，例如 `course-02` |
| 名稱／一句話介紹／價格 | 顯示在卡片上 |
| 連結 | 銷售頁或購買連結 |
| 按鈕文字 | 例如「立即報名」「免費試聽」 |
| 適合人格 | `全部`，或 `知識導師`、`人氣主持人`、`美感創作者`、`療癒陪伴者`、`實驗紀錄家`（多個用逗號隔開） |
| 優先序 | 數字越小越優先推薦 |
| 啟用 | 打勾才會被推薦 |
| 在結果頁顯示 | 打勾才會出現在網站結果頁（不勾＝只在信件裡推薦） |

> 範例資料裡的兩個產品是假的（連結是 example.com），**記得改成你自己的課程**，或取消「啟用」。

### ⚙️ 設定分頁
寄件人名稱、回覆信箱、報告信主旨、寄送時段（預設 9:00–21:00）、每小時最多寄幾封。

### 📊 儀表板分頁
總名單數、訂閱中／已退訂、近 7 天新增、各奶茶人格人數。

## 常見問題

**一天可以寄幾封？**
一般 Gmail 帳號每天約 100 封、Google Workspace 約 1,500 封。超過的會自動留到隔天寄。名單變多時建議改用 Workspace 帳號，或之後換成專業電子報服務（Mailerlite、Brevo 等），名單可以直接從試算表匯出。

**改了 Code.gs 之後要做什麼？**
部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署。網址不會變。

**信被分到垃圾郵件？**
在「設定」填好寄件人名稱，報告信請大家「加入聯絡人」；序列信內容避免一直出現「免費」「限時」等字眼。

**個資提醒**
名單只存在你自己的 Google 試算表。表單上已附「同意接收內容、可隨時取消訂閱」的勾選欄，每封信也都有退訂連結。
